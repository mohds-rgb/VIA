# VIA Demo Dataset

This dataset is intentionally marked **DEMO / PORTFOLIO DATA**.

The operating scenario was supplied by the project owner:

- Operator: Diamond Travel
- Corridor: Damascus ↔ Daraa University Area, Southern Syria
- Fleet: 21 buses
- Capacity: 50 seats per bus
- Service pattern: flexible / approximately hourly
- One-way fare: 50 SYP
- Round-trip fare: 90 SYP

The people listed in `users.json` are fictional development personas. They are not claimed to be real customer accounts or an endorsement by Diamond Travel.

`buses.json` contains 21 portfolio fleet records. `trips.json` contains a representative set of outbound/return schedule records for the demo environment.
