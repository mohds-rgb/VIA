# VIA Specification Baseline

This repository is implemented against the supplied **VIA — Master Engineering, Product, Security, Data-Migration & Delivery Specification, Version 6.1**.

The source specification is the authoritative product baseline for this portfolio project.

Important constraints carried into this repository include:

- Flutter/Dart mobile client
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- FCM
- Cloud Functions 2nd gen / TypeScript
- Android-only V1
- Syria-only V1
- Google Sign-In
- cash-primary booking
- multi-tenant architecture
- capability-based authorization
- server-authoritative business state
- transaction-controlled seat inventory
- idempotency
- Arabic/English localization
- migration-safe updates
- evidence-based release claims

The complete source specification is maintained outside this generated repository package. This document records the baseline and its implementation constraints without claiming that every V1 domain has been completed.
